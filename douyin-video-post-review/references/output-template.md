# Output Template

## Chat Review Format

Use this structure unless Liu Tao asks for another format.

```markdown
刘涛，结论先说：{decision}

数据口径：
- 视频/版本：
- 发布时间：
- 分析截止：
- 已发布时长：
- 数据来源：
- 数据缺失：

表现判断：
- 播放：
- 前 2 秒/跳出：
- 5 秒/完播/平均播放：
- 互动：
- 粉丝/主页：
- 商品/投流：

主要问题：
1. {problem}
2. {problem}

下一条怎么改：
1. {specific correction}
2. {specific correction}
3. {specific correction}

是否改 SOP：
{默认不改 SOP / 建议小改哪一条，原因是什么}

建议沉淀：
{record snippet or target file}
```

## Missing Data Block

If data is incomplete, include:

```markdown
缺失数据：
- 缺少：
- 影响：
- 不影响的判断：
- 下次优先补：
```
