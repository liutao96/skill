## Practical Adjustment to Existing Review SOP

The current review SOP mentions 30 minutes, 3 hours, 24 hours, and 3 days. Keep these as ideal checkpoints, but Liu Tao may only provide screenshots when he remembers.

Use this rule instead:

1. If exact checkpoint data exists, compare against that checkpoint.
2. If only one screenshot/export exists, use the screenshot/export time as analysis cutoff.
3. Always calculate or state elapsed time from posting to analysis.
4. Do not block the review just because some checkpoints are missing.
5. Always record missing metrics as missing, never invent them.

This is a process adaptation, not a full SOP replacement.
