# Note Templates

## Quick Capture

Use when 刘涛 is actively watching a lesson and wants speed.

```markdown
### 快速记录
来源：
归属模块：
小节：

**重点：**

**可复制内容：**

**要回看 / 要验证：**
```

## Standard Lesson Note

Use when turning one lesson into a normal note.

````markdown
## {{lesson_no}}. {{lesson_title}}

### 一句话结论
{{summary}}

### 核心步骤
1. {{step_1}}
2. {{step_2}}
3. {{step_3}}

### 关键参数 / 提示词
```text
{{prompt_or_parameters}}
```

### 示例或截图说明
{{example_explanation}}

### 我的业务应用
{{business_application}}

### 疑问 / 待验证
{{questions}}

### 课后动作
- [ ] {{action_1}}
````

